A self-contained one-page Sunday broadsheet summing up the verified world news of 22 November 2026 (UTC), with three illustrated lead stories, twelve compact story tiles and a dated list of the day's other reports.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Open `page.html` directly to view the newspaper. It uses no external fonts or network resources.
